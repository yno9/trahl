# 繁体字ハイライター

日本語テキスト中に混入した「日本語と形の違う繁体字・旧字体」を検出し、ハイライトするツールです。

雑誌・書籍の校正で、中国語繁体字からの翻訳原稿に残った旧字・繁体を見つける用途を想定しています。

## 使い方

1. https://yno9.github.io/trahl/ を開く（または `index.html` をブラウザで直接開く）
2. テキストを貼り付けて「ハイライト」を押す
3. 黄色くハイライトされた字が、日本語の新字体と異なる繁体字・旧字体です
4. 下の一覧に「検出字 → 日本語の形」も表示されます

ローカルでも使えます（インターネット不要・完全クライアントサイド）。

## 辞書について

- 出典: [OpenCC](https://github.com/BYVoid/OpenCC) の `JPShinjitaiCharacters.txt`（Apache-2.0）
- 約 410 字（新字体と字形が異なる旧字体・繁体字のみ）

**検出する例:** 薰→薫、櫻→桜、說→説、國→国、學→学、會→会、來→来、圖→図 …

**検出しない例:** 書・際・館・作・小・影・文・樹・電・題 など、日本語でも同じ形の字
